### Структура проекта DSP-lab

- labs - набор лабораторных работ для различных эксперементов
- scripts - gnuplot скрипты для постороение графиков
- src - набор модулей реализующих отдельные функции 
- makefile - сборка проекта
- README.md - краткое описание DSP-lab
